# Microsoft 发布 Azure Maia 300 推理系统，并计划 2027 年启动生产部署

## 核心事实

Microsoft 于 2026 年 10 月 12 日宣布 Azure Maia 300：面向长上下文推理、低延迟对话和持续多步智能体任务的推理优先系统。公司称，完整 96 加速器配置在 167kW 功耗包络内提供 27.6TB HBM 容量和 1.7PB/s 聚合 HBM 带宽；其目标是较主流 GPU 系统实现每兆瓦多 40% token，并较 Maia 200 实现最高 7 倍机架级 token 吞吐。Maia 300 使用计算、内存控制器与 I/O 分离的多芯粒架构，计算芯粒基于台积电 N2P 工艺；Microsoft 计划在 2027 年开始生产部署，并将 Maia 扩展至多吉瓦规模。以上性能、部署和扩张计划均为 Microsoft 公司口径，尚无独立性能或量产验证。

## 投资含义

这是超大规模云厂商从购买通用 GPU 转向自研推理系统的可观察动作，重点应跟踪 2027 年生产部署节奏、Maia 在 Copilot/Foundry/GitHub 等负载的实际占比，以及单位 token 成本和电力效率能否兑现。受益链条与压力需分开验证：台积电 N2P 制程、HBM 和定制封装/网络需求是明确技术路径；但这份公告不能单独推导对任何通用 GPU 供应商的份额或收入影响。

## 建议动作

跟踪 2027 年生产部署、实际工作负载覆盖、单位 token 成本与能效的独立验证。
