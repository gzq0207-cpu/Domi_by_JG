# NVIDIA 与 Microsoft 推出 RTX Spark Windows 预售，并预览 DGX Station for Windows

## 核心事实

NVIDIA 于 2026 年 10 月 7 日宣布 RTX Spark 面向 Windows 开放预售，并预览 DGX Station for Windows。按 NVIDIA 口径，RTX Spark 采用 Blackwell RTX GPU 与 Grace CPU；DGX Station for Windows 采用 GB300 Grace Blackwell Ultra Desktop Superchip，配置 748GB 统一内存，并称可本地运行最高万亿参数规模的模型。产品规格、性能及适用模型规模均为 NVIDIA 公司披露，未作独立测试。

## 投资含义

事件把高内存、本地 AI 工作站由开发者设备延伸至 Windows 企业桌面。价值捕获需观察整机实际交付、渠道与企业 IT 采购周期，并在相同模型、量化、上下文长度和并发条件下验证本地推理吞吐、功耗和总拥有成本；“可运行万亿参数模型”不能直接等同于可用的交互性能或企业部署规模。

## 建议动作

关注预售转交付、系统定价与企业部署反馈
