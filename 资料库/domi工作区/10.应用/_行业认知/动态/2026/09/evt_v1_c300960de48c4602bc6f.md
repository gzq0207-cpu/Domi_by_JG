# Microsoft 发布新版 Copilot：Home、Code 与 Autopilot（公司口径）

## 核心事实

Microsoft 于 9 月 25 日发布新版 Copilot：Home 将 Chat 与 Cowork 汇集，并整合 Word、Excel 和 PowerPoint；Code 允许用户以自然语言构建应用、仪表盘、自动化和工作流；Autopilot 是可在用户离开后持续执行任务的云端智能体。公司称 Home 与 Code 将先向 Frontier 项目逐步推出，Autopilot 将于月末扩大至私有预览；Code、Cowork 与 Autopilot 按用量计费。产品可用范围、效果与单位经济性均尚待独立验证。

## 投资含义

产品形态从单轮辅助转向长任务委派、自然语言构建和受治理的运行时，企业 AI 竞争的价值捕获点可能上移至身份权限、组织数据上下文、运行托管和按任务计费。发布不代表企业已获得生产率回报；后续应验证 Frontier 到广泛可用的转化、任务成功率与人工复核成本、用量收费下的客户预算和留存，以及第三方插件对平台控制权的影响。

## 建议动作

跟踪正式可用范围、真实任务成功率、单位任务成本、客户用量和续费，以及插件/运行时生态的采用。
