# Meta 发布 Muse Wonder 与 Muse Wonder Full，主打长程智能体记忆和目标专注能力

## 核心事实

Axios 于 2026 年 10 月 12 日报道，Meta 发布 Muse Wonder 和 Muse Wonder Full：前者可通过 Meta Model API 与 Muse Code 使用，后者面向 Muse Code 订阅用户。报道引述 Meta 表示模型面向个人和专业智能体、记忆与代码任务，并突出 Active Memory 与 Active Focus；Meta 称模型训练使用其 Prometheus 数据中心。报道同时称 Meta 尚未说明 Wonder 系列是否会开放权重，另有 Muse Glimmer 的权重已开放。模型能力、训练基础设施和可用范围主要是 Meta 口径，未取得 Meta 的同日原始公告或独立测试。

## 投资含义

这是闭源前沿模型向长程智能体记忆、持续目标执行与订阅产品分发倾斜的供给信号。尚不能从媒体报道推导独立性能领先、用户留存或收入贡献；需要跟踪模型卡、可复现评测、实际功能上线范围、隐私和安全控制，以及从 API/订阅到消费级产品的变现数据。

## 建议动作

跟踪 Meta 原始模型卡、公开可用范围、第三方评测与隐私安全披露
