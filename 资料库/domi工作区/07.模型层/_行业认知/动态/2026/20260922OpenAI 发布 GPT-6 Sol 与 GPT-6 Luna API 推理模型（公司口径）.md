# OpenAI 发布 GPT-6 Sol 与 GPT-6 Luna API 推理模型（公司口径）

## 核心事实

OpenAI API Changelog 于 2026 年 9 月 22 日宣布 GPT-6 Sol（gpt-6-sol）与 GPT-6 Luna（gpt-6-luna）上线 Responses API 和 Chat Completions API。官方称两者均接受文本和图像输入并输出文本；标准档、提示词不超过 272K token 时，Sol 定价为每百万 token 输入 2 美元、缓存输入 0.20 美元、输出 10 美元，Luna 为输入 0.10 美元、缓存输入 0.01 美元、输出 0.50 美元。

## 投资含义

这是闭源基础模型供给与价格梯度的可观察更新：高能力 Sol 与低成本 Luna 并行，可能扩大不同推理预算下的部署选择。但公告未提供独立基准、实际单位推理成本或客户采用数据，不能据此推断市场份额或开发者迁移。后续应跟踪第三方评测、上下文长度下的有效价格、API 调用量和企业迁移。
