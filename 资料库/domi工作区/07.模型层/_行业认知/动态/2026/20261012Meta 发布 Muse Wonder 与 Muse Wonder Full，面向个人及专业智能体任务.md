# Meta 发布 Muse Wonder 与 Muse Wonder Full，面向个人及专业智能体任务

## 核心事实

Meta 于 2026 年 10 月 12 日发布 Muse Wonder 与 Muse Wonder Full，称其为面向个人及专业智能体任务的最新模型系列。Muse Wonder 当日通过 Meta Model API 和 Muse Code 向开发者与构建者提供，Muse Wonder Full 当日面向 Muse Code 订阅者提供；Meta 表示 Muse Wonder 将陆续进入 Muse，先向订阅者推出。公告描述的能力包括跨对话保留相关信息的 Active Memory，以及在任务受阻时尝试其他方法、从错误中恢复的 Active Focus；法律、金融、健康和编程示例均为公司对目标使用场景的表述，未提供独立基准或商业化数据。

## 投资含义

该发布把模型供给、面向开发者的 API/代码产品和订阅入口同时绑定，后续应跟踪可用区域、价格与模型调用限制、第三方评测、Active Memory 的隐私/安全实现，以及是否转化为订阅和 API 用量。Meta 所称“前沿”能力和安全训练是公司口径，不能据此直接比较与其他模型的客观性能或推导收入贡献。

## 建议动作

跟踪 API、Muse Code 与订阅端的实际可用性、价格、第三方评测及安全报告。
