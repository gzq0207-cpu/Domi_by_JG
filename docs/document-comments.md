# 文档评论与逐条跳转

Domi 内打开的 Markdown、PDF、Word 和主题研究笔记使用同一套文档评论。无需创建研究主题，就可以给材料添加评论。

选中文字后点击浮动工具条的“评论”，在评论面板输入并保存；PDF 的图表或扫描页可以先“框选区域”，再写评论。没有选段时，点击文档顶部“新增评论”，即可评论整篇文档。

顶部“评论 N”展开或收起评论列表。点击某一条评论，正文会滚动到对应位置并短暂突出显示；“上一条”“下一条”按原文位置逐条浏览，到末尾后循环。整篇文档评论放在列表最前，定位到文档开头。PDF 选段按页码和页面位置排序，跳转会自动打开对应页面，缩放与旋转不改变批注位置。窄面板中，评论列表停靠在正文下方。

评论可以编辑和删除。删除选段评论会保留原有高亮及来源身份，已加入主题研究的摘录与评论快照继续保留。主题研究文档本身也支持评论，包括自由分析、可编辑的笔记评论以及只读摘录；只读摘录上的评论通过稳定的笔记 ID 定位。

评论正文与位置保存在当前资料库的 `.domi/research.sqlite3` 中，不写入原始 Markdown 或 PDF。请随资料库一起备份隐藏的 `.domi` 目录；只复制原始文档不会携带这些评论。尚未保存的评论会缓存在本机，重新打开文档可恢复草稿。保存和取消草稿前暂停逐条跳转，避免切换时丢失正在输入的内容。

其他窗口修改同一评论时，保存会提示冲突并保留输入内容。点击“载入最新评论并保留草稿”，对照下方最新评论合并，再保存；不会直接覆盖其他窗口的修改。材料正文正在编辑时，创建选段评论前先保存正文；正文保存失败时保留评论草稿。

来源内容改变后，Markdown 只在原文及上下文能够唯一匹配时重新定位；重复或消失的选段会提示无法定位。PDF 的文件版本改变后保留评论，但不把旧坐标画到新页面上。材料改名或移动后的身份恢复沿用研究批注的来源身份机制。

PDF 和 Word 创建批注前会核对当前阅读版本。打开后原件被其他应用修改时，需重新载入再批注；PDF 预览令牌绑定具体内容版本，不会让旧阅读器继续取到新文件的页面内容。

验证命令：`npm run test:research`。覆盖评论排序、唯一定位、多主题快照边界、评论编辑冲突和删除、SQLite 重启恢复，以及真实 Electron 编辑器中的选段与整篇评论、逐条跳转、PDF 跨页定位、只读摘录评论、本机草稿恢复。

## Word 直接阅读与批注

文档库可以直接打开 `.docx`，无需预先转换为 Markdown，也无需安装 Word。阅读器显示正文段落、基本文字格式、表格和图片。选段后可高亮、评论、加入主题研究或引用提问；点击图片可添加图表评论并保存图片摘录。评论仍通过同一套列表及上一条／下一条定位，跨格式文字和跨段落选区均保留文字位置。

旧版 `.doc` 会在本机转换为 DOCX 阅读预览。Windows 优先使用已安装的 LibreOffice，否则使用本机 Microsoft Word；macOS 和 Linux 使用已安装的 LibreOffice。转换结果按原件内容版本缓存，原件保持不变。没有可用转换器或转换失败时显示明确错误，可先在外部另存为 `.docx` 再打开。

此版本提供阅读与批注，不编辑 Word 正文。复杂分页、浮动排版、自动编号、域和公式可能与 Word 不同；检测到未展开的页眉页脚、脚注、文本框、公式或嵌入内容时会提示提取缺口，问答不会将其标成完整原文。需要精确核对时可用原生 Word 打开。

Word 参与文档库搜索、选定材料问答和主题来源回跳。引用 Word 中的文字时，来源仍是原始 Word 文件；不会自动扩展到其他文件。Word 改变后，文字批注只在选段唯一匹配时恢复显示；旧版图片位置不套用到新文件。

## 导出带批注副本

PDF 和 Word 的阅读工具栏提供“导出带批注副本”。选择保存位置后生成独立副本，完成后可以点击“打开副本”在外部应用查看。不会覆盖原始文件；取消保存对话框也不写入文件。未保存的评论需要先保存或取消。

- PDF 输出 `.pdf`，写入原生文字高亮、区域框与中文评论，保留原来的页面、旋转和批注。高亮具有文件内的显示外观，外部阅读器可直接显示；评论通过阅读器的批注功能查看。
- Word 输出 `.docx`，在选中文字或图片处插入原生范围评论，文字选段同时写入高亮。正文、文字格式、表格、图片、已有原生评论及其他原始部件继续保留。旧版 `.doc` 同样输出为 `.docx` 副本。
- 原件中的外部批注会随副本保留，当前不会自动导入 Domi 的评论列表，也不提供双向同步。
- 若批注来源版本已变化，默认暂停导出，避免将旧位置写入新文件。可选择“将失效批注保留为文档评论并导出”：旧摘录和评论会带上“未定位”说明保存，原来的图表截图继续留在 Domi。导出过程中正文或评论再发生变化时，会中止并提示重试。

`npm run test:word` 包含原生批注文件检查与真实 Electron 的 Word/PDF 操作、导出、回读及原件不变检查。Windows 安装 Microsoft Word 后可另运行 `npm run test:word-office`：真实打开导出 DOCX、核对评论与图片范围、渲染并验证二进制 DOC 的生产转换流程。
