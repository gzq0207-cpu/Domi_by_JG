# 主题研究

在左侧点击“主题研究”，选择所属行业、输入名称并新建主题。每个行业文件夹下都有自己的 `主题研究/`，例如 `03.算力芯片/主题研究/<主题名--稳定ID>/研究笔记.md`；图表截图放在同目录的 `assets/`。可以自由写作、插入图片和表格、调整章节。重命名主题不会改变目录及内部身份。主题列表统一展示各行业的主题，支持按主题名或行业名搜索。

阅读材料时新建主题，默认采用材料所在行业，也可以手动选择。研究文档顶部的行业选择器可调整已有主题归属，连同笔记和截图一起移动，保留稳定 ID，并重新计算来源相对链接。旧版根目录 `14.主题研究/` 下的主题会自动迁移；有明确行业元数据或唯一来源行业时沿用该行业，无法确定的放入 `_其他行业/主题研究/`，供后续调整。迁移遇到目标目录冲突时保留原文件并提示，不覆盖已有目录。

从文档库打开 Markdown 或 PDF。Markdown 默认阅读模式，可以切换到编辑；选中文字后出现“高亮”“评论”“加入主题研究”。PDF 还提供页码、缩放、旋转、搜索及“框选区域”，扫描页和图表可以保存截图。

点击“加入主题研究”可搜索、多选或新建主题。确认后，摘录和评论进入各主题的“待整理笔记”。可以使用拖动把手或“移动到章节”整理摘录；原文摘录保持只读，评论可以编辑。点击来源按钮可对照原文。窄窗口提供研究文档与来源材料切换。

需要边读边问时，选中文字后点击“引用提问”。材料正文、PDF 文字、研究文档中的分析和评论、只读摘录都支持。选段连同出处加入当前对话的提问框，可继续引用其他段落，写好问题再发送；引用不会自动生成批注或笔记。来源文档会加入本轮选定材料范围，主题笔记中的原文链接不会自动扩展该范围。详见 [文档引用提问](document-scoped-qa.md)。

提问时可点击“已有资料”“模型直答”或“Both · 两者结合”。已有资料要求原文依据，模型直答只使用问题、主动引用选段和通用知识；Both 在同一份回答中分列资料回答和未经资料核验的模型补充。切换方式会保留草稿和选段，后续引用沿用已选方式。

仅高亮或评论也会保存为材料批注。点击已有高亮或“批注”列表，可以继续编辑、加入其他主题，或查看已经加入的主题。同一批注加入多个主题时保存独立快照；修改某个主题的评论不会改写其他主题，也不会改写原始材料。移除摘录仅影响当前主题。

Markdown、PDF 和研究文档自身均提供“评论 N”“新增评论”和上一条／下一条。选段评论、整篇评论与 PDF 图表评论可以集中浏览，点击定位原文；评论编辑和删除不影响已收集到其他主题的快照。操作、草稿与备份规则见 [文档评论](document-comments.md)。

主题正文以 Markdown 为准。摘录使用可读 Markdown 与 `domi:note` 边界标记，编辑器保存时保留稳定 ID。资料库内 `.domi/research.sqlite3` 保存批注锚点、材料版本、主题关联及可重试操作记录。备份整个资料库时应包含隐藏的 `.domi` 目录；只复制主题目录可以保留正文和截图，精确回跳仍依赖批注数据库与来源材料。

打开来源时会检查版本。唯一的同内容文件移动后可以重新定位；来源改变、缺失或存在多份候选时显示提示，保留已有摘录。保存使用版本检查与原子替换；外部修改冲突时保留本机草稿，提供复制草稿和保留备份后重新载入。加入新摘录前会先保存已打开的主题文档，完成后更新摘录而保留编辑位置。

PDF 渲染器、Worker、中文字符映射、标准字体和 WASM 均随应用本地打包。第一版不调用 AI 整理服务。主题笔记可以作为现有文档问答的选定材料；其中的来源链接不会自动授权读取其他文件。

验证命令：`npm run test:research`，包含存储测试及真实 Electron/preload/IPC/PDF 协议的交互测试。界面测试使用编译后的 `file://` 页面与 Electron 沙箱，阻止 HTTP 网络请求，验证本地 Worker、字体和 PDF 渲染。测试使用临时资料库、临时用户目录和隐藏窗口，不访问正式资料或模型 API。
