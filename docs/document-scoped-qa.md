# 指定文档范围问答

提问框提供三个“回答方式”按钮，发送前可以随时切换，问题、引用和已选文档继续保留：

| 方式 | 回答依据 | 来源显示 |
| --- | --- | --- |
| 已有资料 | 选定文档，也可通过资料范围选择全库资料；不以模型通用知识补全资料缺口 | 关键结论附可回查原文引用；资料不足时明确说明 |
| 模型直答 | 当前问题、用户主动提供的引用选段和模型通用知识；本轮不读取资料、网页或历史对话 | 显示“模型直答 · 未读取资料”，不生成资料核验标记 |
| Both · 两者结合 | 选定文档加上模型通用知识；不联网，也不扩展文档范围 | 依次显示“基于已有资料”和“模型补充（未由资料核验）”；原文引用只用于资料章节 |

三个方式都沿用输入框当前选中的模型。Both 在同一份回答中分列两类依据。选择会随当前对话草稿保留，后续修改只影响之后发送的问题，已排队的问题保留发送时的方式。模型直答下已选文件保留供切换方式，实际不提交给模型读取；主动引用的文字选段仍作为用户提供的内容进入问题。

引用提问默认采用“已有资料”；已经手动选了“模型直答”或 Both 后，继续引用不会重置选择。原有“全库＋联网研究”与工作流入口仍用于开展完整研究或其他任务；点击上述三个按钮则进入对应的只读问答方式。

在任一对话的输入框输入 `@`（也支持全角 `＠`），会出现资料库文档候选。继续输入文档名或所在文件夹可筛选，候选同时显示文件名和目录以区分同名文件。点击候选，或用 ↑↓ 选择后按 Enter / Tab 添加；此时只添加材料，不发送问题。可多次输入 `@` 添加不同文档，已选文件不会重复添加。中文输入法确认候选词时不会选中文档或发送问题；邮箱和网址中的 `@` 不触发文档候选。Esc 关闭候选，Shift + Enter 继续换行。

**通过 `@` 添加文档后，自动切到「已有资料 / 仅选定材料」**，包括之前处于模型直答、Both 或联网研究的情况。已写的问题、已有材料和引用仍然保留；输入框下方显示本轮选定文档，支持逐份移除，范围会保留供连续追问。模型只读取选定的文件；输入 `@` 搜索目录本身不把其他候选正文提交给模型。输入框未完成候选选择时，Enter / Tab 用于选择，不会直接发送问题。

批量选择仍可点击输入框下方带 `@` 图标的「选择文档」（已有选择时显示「已选 N 份文档」），按文档名或文件夹搜索，勾选所需材料，点击「仅用这 N 份文档」。也可通过「＋」添加本地 Markdown、文本、PDF 或 Word，并把「资料来源范围」设为「仅选定材料」。全局搜索的「加入提问」会自动启用这个模式。

阅读 Markdown、PDF、Word 和主题研究笔记，或编辑 Markdown 时，也可以选中文字，点击浮动工具条的「引用提问」。选段会以引用卡片加入当前对话的提问框，显示原文、文件名、章节或 PDF 页码，并把来源文件加入选定范围；已写的问题和已选文档继续保留。引用操作不会自动发送、创建批注或加入主题，补充问题后再发送即可。

可连续引用不同段落或不同文档，一轮最多 12 段，每段最多 12,000 字。同一选区重复引用会去重；每张引用卡片可单独移除，也可点击出处打开文档核对。引用和问题草稿随当前对话保存，重开后恢复。发送或加入队列后清空本轮引用，文档范围继续保留供追问；移除某份文档或调整范围时，其未发送引用也会移除。

引用保存的是选中时的文字快照。已有资料回答和 Both 的资料章节会读取选定文档核对上下文和版本，再提供原文证据；模型直答只接收主动引用的文字，不读取来源文件。主题笔记里的材料来源链接不会自动加入范围。研究笔记有未保存草稿或保存冲突时先保存或处理冲突，成功后再进入提问。

选择“已有资料”且限定文档范围时，回答依据选定文档，关闭联网、全库检索、外部连接、Shell、插件和记忆；每轮启用独立的只读资料会话，不把历史回答作为证据。选定范围会随当前对话草稿保存，发送后保留，方便连续追问。点击「调整范围」或移除材料可修改下一轮的范围；已经发出或排队的问题保留发送时的范围。

关键结论使用资料工具绑定逐字引文。点击回答中的 `[1]` 等引用可查看绑定结论、原文、来源版本、章节和页码或行号，再点击「定位核验原文」打开原文。文件版本改变、引文不匹配或未实际提供原文时，不显示成已通过核验的引用。引用核验检查原文存在性和绑定关系，不替代对推断本身的判断。

每轮最多 64 份文档。勾选文件夹会展开为当前目录快照中的具体文件，之后新增文件不会自动进入范围。目录不完整时会显示提示，可通过全局搜索或本地文件选择补充。长文按需续读；扫描 PDF、提取失败、未读完或预算不足会显示覆盖缺口。文档中没有足够依据时应明确说明，不用范围外知识补全。

验证：`npm run test:document-scope` 覆盖选择、发送、连续追问、调整、取消、刷新恢复、来源隔离以及引用原文定位。UI 测试使用临时文件和确定性模型输出，调用真实资料读取与引用校验服务，不访问模型 API 或用户资料库。
